## 项目简介 / About

Lyra 是一个基于 **Jetpack Compose + Media3** 的原生 Android
音频播放器。它不构建公共云端服务，而是在用户完成账号授权的前提下提供
在线内容的搜索与播放，同时把本地播放、下载、缓存、歌单管理和
备份/同步能力做完整。

当前定位：

- **账号即能力**：在线内容需要用户在设备上自行完成授权登录，
  授权信息只保存在本地。
- **本地优先**：播放缓存、下载文件、歌单、历史记录、设置与授权信息
  默认保存在设备本地。
- **可选同步**：可将歌单、收藏、最近播放与播放统计等元数据
  同步到用户自己控制的远端存储，不会上传到维护者的中心化服务。
- **尊重隐私与账号安全**：不接入广告 SDK、第三方统计或崩溃分析 SDK；
  应用不会把本地播放历史或统计回写到任何在线服务。
- **单 Activity + Compose 架构**：`MainActivity` 是唯一对外入口，
  UI 由 Compose `NavHost`、动态底栏、Mini Player 与 Now Playing 覆盖层组织。
- **启动与恢复链路**：正常启动流程为
  `Loading -> Disclaimer -> Main`；
  如果上次启动发生崩溃或系统 ANR，会先进入 `Safe Mode`。
- **测试护栏**：下载存储、同步合并、歌词解析、播放策略、
  配置备份与安全模式等关键链路都有对应单元测试或设备测试。

## 项目亮点 / Why it stands out

- **本地优先，也认真做脱机体验**：
  `NetworkStatusMonitor` 基于系统默认网络承载自动识别脱机状态，
  `offlineCachedImageRequest` 会在脱机时阻断远程图片请求并优先使用缓存；
  首页、探索、播放页、歌词页、歌单和下载列表都会接收 `offlineMode`，
  网络断开时仍能围绕本地文件、已下载音频、播放缓存、缓存封面和本地歌单继续使用。
- **播放韧性不是简单的失败重试**：
  `PlayerManager` 负责解析、队列与失败恢复；当前内容不可播时会先尝试
  可用的降级策略，必要时自动匹配可播放候选兜底；播放异常时还会刷新
  当前链接，连续失败再跳过或停止。
- **多级会话回退**：
  登录态会保留有效身份信息，并与匿名会话分别维护缓存；
  失效的播放候选会进入备用链路，避免在同一候选上反复重试。
- **GLSL/AGSL 高性能流体背景**：
  播放页动态背景由 `BgEffectPainter` 加载
  `assets/shaders/hyper_background_effect.glsl` 并通过 `RuntimeShader` 逐帧渲染；
  shader 内部基于封面取色、动态色块和轻量颗粒噪声生成流体背景，
  并接入 `uMusicLevel / uBeat` 做音频响应，不是简单把封面做高斯模糊。
- **深度歌词体验**：
  `SyncedLyricsView` 与 `AdvancedLyricsView` 支持逐行、逐词/逐字 LRC（含行尾
  时间和方括号逐字时间戳）以及 TTML 歌词的高亮、翻译歌词、
  音译显示、歌词偏移、点击跳转、长按分享、景深模糊、边缘渐隐和全屏歌词；
  `LyricShareSheet` 可选择歌词行，复制文本、分享歌曲或生成 1080px 歌词卡片；
  歌词逐行高亮同时按行范围与原时间戳做亮度插值，支持拖动跳转。
- **可恢复的启动与运行**：
  崩溃或 ANR 后进入安全模式，保留崩溃日志与 ANR 记录，
  安全模式下禁用高风险模块，便于定位问题。
- **原生桌面集成**：
  提供桌面小组件、启动器快捷方式、投屏/输出设备选择以及
  悬浮歌词与状态栏歌词，播放状态与系统媒体控制保持同步。

## 快速体验 / Getting Started

### a. 下载 Release 版本（推荐）

1. 前往本仓库的 Releases 页面下载最新版本。
2. 如何选择版本？
- 大部分手机请选择 `arm64-v8a`
- 老旧 32 位设备请选择 `armeabi-v7a`
- `x86` / `x86_64` 主要用于模拟器、英特尔设备或 Chromebook

> [!IMPORTANT]
> Release 渠道不是严格意义上的稳定通道。版本通常在完成一批功能后手动发布，
> 仍可能包含未充分暴露的问题。

### b. 下载 CI 版本

1. 前往本仓库的 Actions 页面，
   下载最近一次成功构建的 Artifacts 并解压。

> 默认 CI 上传 `arm64-v8a` APK；手动 Release 流程会构建多 ABI APK。

### c. 本地构建

1. 克隆仓库并初始化子模块：
   ```bash
   git clone --recursive <本仓库地址>
   cd Lyra
   ```
2. 使用 Android Studio 最新稳定版打开项目并同步依赖。
3. 构建调试版：
   ```bash
   ./gradlew :app:assembleDebug
   ```
4. 安装 APK：
   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```
5. 首次启动只需阅读免责声明；播放通知权限可在设置页「通用」里手动开启，
   本地音乐权限在你扫描本地文件时按需申请。
6. 如需调试工具，在设置页连续点击 **版本号** 7 次启用开发者模式，
   底栏会出现独立 `Debug` 页面。

> DEBUG 构建仅用于测试，性能和体积不代表发布版。

发布版构建与签名流程请参阅
[CONTRIBUTING.md](./CONTRIBUTING.md#构建发布版--release-build)。

## 核心特性 / Key Features

- 🎧 **本地曲库与在线播放**：
  本地文件扫描、导入、下载与缓存；完成账号授权后可使用搜索、
  歌单、收藏与艺人页等在线能力。
- 🏠 **首页与继续播放**：
  首页展示常用歌单、推荐与继续播放；推荐分区可按需刷新。
- 🗂️ **媒体库分类浏览**：
  `Library` 按本地、收藏与在线内容分组，支持二级分类与搜索。
- 🎼 **歌单与收藏**：
  支持创建歌单、导入导出、批量下载、收藏歌曲与关注艺人；
  歌单详情页统一使用封面主色背景，列表与操作按钮按背景亮度取色。
- ▶️ **播放控制**：
  完整播放队列、随机与循环、断点续播、播放失败自动恢复；
  队列支持添加下一首、队尾、移除与拖动排序。
- 🎤 **歌词**：
  逐行、逐词、翻译与音译歌词，支持偏移调整、点击跳转、
  全屏歌词、悬浮歌词、状态栏歌词与歌词卡片分享。
- 🎨 **界面与动效**：
  流体动态背景、玻璃质感底栏、迷你播放器横滑切歌、
  播放页封面飞行动画与封面主色主题。
- 📥 **下载与备份**：
  下载管理与缓存清理、配置导出与恢复，以及可选的远端元数据同步。
- 🧩 **桌面集成**：
  桌面小组件、启动器快捷方式、投屏与输出设备选择。
- 🛡️ **稳定性**：
  安全模式、崩溃日志、ANR 记录与调试探针。

## 实现概览 / Implementation Notes

### 构建与版本

- 原生 Android，Kotlin + Jetpack Compose。
- `minSdk 28`，面向 Android 9 及以上设备。
- 使用 Media3 负责播放与系统媒体控制。
- Gradle 多 ABI 构建，Release 由 CI 使用受控签名密钥完成。

### 模块结构

- `app/`：应用主体，包含 UI、播放核心、数据层与本地存储。
- `core/`：播放、数据、同步、日志等基础设施。
- `ui/`：Compose 页面、组件与主题。
- `data/`：Room、DataStore 与仓储实现。
- `docs/`：内部设计说明与重构记录。

### 入口与导航

- `MainActivity` 是唯一入口，Compose `NavHost` 组织页面。
- 动态底栏、Mini Player 与 Now Playing 覆盖层贯穿主要页面。
- 页面跳转与播放状态通过统一的 ViewModel 与状态流驱动。

### 播放、缓存与服务

- `PlayerManager` 持有当前队列、索引与播放状态，并负责失败恢复。
- 播放缓存与下载文件独立管理，脱机时优先使用本地内容。
- 系统媒体控制通过 MediaSession 与通知保持同步。

### 本地数据与安全

- 歌单、收藏、历史与统计保存在本地数据库。
- 设置与偏好使用 DataStore 持久化。
- 授权信息与同步凭据使用系统 Keystore 加密保存。
- 配置导出文件包含敏感信息，仅供自用迁移，不应公开分享。

## 能力边界 / Known Limitations

- 在线内容的可用性取决于用户账号的授权范围与对应规则，
  部分内容可能因权限或地区限制不可播放。
- 本项目不提供绕过付费、DRM 或地区限制的能力。
- 歌词与封面匹配基于公开信息，可能存在延迟或误差，可手动调整。
- 播放稳定性受网络状况与在线服务状态影响。
- 部分高级功能依赖系统版本与设备能力。

---

## 数据与隐私 / Privacy

- Lyra 不提供自己的公共云端媒体分发服务，也不接入广告 SDK、
  第三方统计或崩溃分析 SDK。
- 播放缓存、下载文件、本地歌单、历史记录、播放统计、设置与授权信息
  默认保存在用户设备本地。
- 如用户主动开启远端同步，仅同步歌单、收藏、历史和播放统计等元数据。
- 不会将音频缓存、下载文件、登录凭据或播放令牌上传给开发者。
- 默认关闭 Android 系统云备份 / 设备迁移。
